# Tier I — Foundational Renewal Dynamics

This directory collects the foundational mathematical and physical plates of the Renewal Continuum, preceding the Tier II Interaction Layer.

Placement follows each plate's conceptual role and internal chronology. A version number alone does not establish canonical Tier membership. Preserve the plate's original title, version, equations, and authorship when relocating it.

For the repository-wide organization and naming standard, see [Codex Directory Reference](../../Foundations/Codex_Directory_Reference.md).
